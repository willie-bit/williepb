# 가족 자산 관리 서비스 — 초안 설계서 (v0.1)

> 작성일: 2026-04-21
> 상태: 초안 (Draft)
> 목적: 가족 단위의 전 자산(부동산·금융·암호화폐·금·자동차·대출·카드·기타 실물)을 통합 관리하고, 일별 시세 갱신·포트폴리오 분석·세무 계산·제안(Insight)을 제공하는 웹/모바일 서비스의 초기 설계 방향을 정리한다.

---

## 1. 서비스 개요

### 1.1 한 줄 정의
가족 구성원 전원의 자산·부채·현금흐름을 **하나의 뷰**로 통합하고, 매일 자동 갱신되는 시세와 세무·포트폴리오 인사이트를 제공하는 "패밀리 자산 대시보드".

### 1.2 핵심 가치 제안
- **통합 뷰(Single Source of Truth)**: 구성원별·계좌별로 흩어진 자산을 가족 단위로 합산·분해해서 본다.
- **매일 업데이트**: 시세·환율·카드 사용내역이 매일 배치로 갱신된다.
- **세무 내장**: 보유세·양도세·금융소득종합과세 시뮬레이션을 자산 데이터와 바로 연결.
- **Insight**: 포트폴리오 평가, 리밸런싱 제안, 섹터/자산군 편중 경고, 관심 종목 트렌드 제공.

### 1.3 사용자(페르소나)
- **가족 대표(Owner)**: 전체 자산을 총괄, 구성원 초대·권한 부여, 세무 시뮬레이션 주도.
- **공동관리자(Co-admin)**: 배우자 등. 본인 계좌 연동 및 자산 입력, 전체 조회.
- **조회자(Viewer)**: 성년 자녀 등. 허용된 범위만 조회.

## 2. 범위 및 주요 기능

### 2.1 자산 카테고리

| 카테고리 | 데이터 소스 (권장) | 자동화 수준 | 비고 |
|---|---|---|---|
| 부동산 | 국토부 실거래가 OpenAPI, 한국부동산원 R-ONE, KB시세(대체 수단 검토) | 자동(일/주) | 보유세·양도세 계산 연동 |
| 주식·ETF·펀드 | 마이데이터 중계 / 오픈뱅킹 / 증권사 OpenAPI(키움·한투 등) | 반자동 | 계좌 여러 개 통합 뷰 |
| 연금(국민·퇴직·개인) | 마이데이터(연금 정보), 통합연금포털 조회 데이터 | 반자동 | 세제혜택 추적 |
| 현금·예적금 | 오픈뱅킹 / 마이데이터 | 자동 | 목표 예산 연동 |
| 암호화폐 | 업비트 Open API, 빗썸 API | 자동 | 매수가·현재가·평가손익 |
| 금 | 한국금거래소/KRX 금시장 시세, LBMA 국제가, 금 ETF(종목코드) | 자동 | 현물+금융상품 합산 |
| 자동차 | KB차차차/엔카/보험개발원 시세(공식 API 유무 확인 필요) | 반자동 | 감가상각 모델 병행 |
| 카드 지출 | 마이데이터(카드사) / 카드사 앱 CSV | 자동/수동 | 월별·카테고리별 집계 |
| 대출 | 마이데이터(대출정보), 수동 입력 | 자동+수동 | 잔액·금리·상환 스케줄 |
| 기타 실물 | 수동 입력(시계·미술품·귀금속·수집품 등) | 수동 | 평가일·평가액 이력 |

### 2.2 기능 리스트 (MVP → v1 → v2)

**MVP (3개월 내)**
- 가족/구성원/권한 모델
- 계좌·자산 수동 입력 + CSV 업로드
- 국토부 실거래가·업비트·KRX(주식·금 ETF) 연동 (공개 API부터)
- 일별 시세 배치(Cron)
- 총자산 대시보드, 자산군별 비중 파이차트, 시계열 추이
- 월별 손익(실현/미실현 분리) 및 월별 현금흐름(카드값·수입)

**v1 (6개월 내)**
- 마이데이터 중계사(예: 뱅크샐러드/토스 SDK) 연동 → 은행·카드·증권·대출 자동 수집
- 보유세/양도세/금융소득종합과세 계산기
- 환율 자동 반영(해외 자산)
- 알림(카드 결제일, 대출 금리 변동, 자산 급등락)
- 포트폴리오 리밸런싱 제안(타깃 비중 대비 편차)

**v2**
- 은퇴·교육자금 시뮬레이터(몬테카를로)
- 상속/증여 플래너
- 관심 종목 트렌드(뉴스·거래대금·공시 기반) 정보 제공
- 부동산 매수/매도 시나리오 비교

### 2.3 비기능 요구사항
- **신뢰성**: 일 배치 실패 시 재시도·알림. 최근 값 폴백.
- **보안**: 전 구간 TLS, 민감데이터(토큰·계좌번호) KMS 암호화, 2FA, 감사 로그.
- **개인정보**: 수집·이용·제3자 제공 동의, 마이데이터 약관 준수, 구성원 탈퇴/삭제 요청 대응.
- **성능**: 대시보드 첫 페인트 < 2s, 일 배치 < 30분.
- **감사·백업**: 일별 스냅샷 보관(최소 5년), 세무 계산 근거 데이터 보존.

## 3. 시스템 아키텍처 (개요)

```
[Web/Mobile Client]
        │ HTTPS
        ▼
[API Gateway] ── [Auth/IAM: OAuth2 + 2FA]
        │
        ▼
[Application Services]
 ├─ Household / Member / Permission
 ├─ Asset Registry (부동산·주식·코인·금·차·실물·대출)
 ├─ Portfolio & Analytics
 ├─ Tax Engine (보유세/양도세/종합과세)
 ├─ CashFlow (카드/수입/예산)
 └─ Insight / Notification
        │
        ▼
[Integration Layer]
 ├─ MyData Broker Adapter (은행/카드/증권/대출)
 ├─ Open Banking Adapter
 ├─ Market Data Adapter (KRX, Upbit, LBMA, FX)
 ├─ Real Estate Adapter (국토부/부동산원/KB)
 └─ Vehicle Price Adapter
        │
        ▼
[Data Stores]
 ├─ OLTP: PostgreSQL (사용자·계좌·포지션·거래)
 ├─ Time-Series: TimescaleDB or InfluxDB (일별 시세·스냅샷)
 ├─ Cache: Redis (세션·시세 핫캐시)
 ├─ Object Storage: S3 (CSV 업로드·보고서 PDF)
 └─ Secret: KMS/Vault (토큰·API 키)

[Scheduler/Workers]
 └─ Cron/Queue (일 시세 배치, 환율, 스냅샷, 알림)
```

### 3.1 기술 스택 제안 (초안)
- **백엔드**: Python(FastAPI) 또는 Node.js(NestJS). 세무·수치 계산 많아 Python 유리.
- **프론트엔드**: Next.js + TypeScript, 차트는 Recharts/ECharts.
- **DB**: PostgreSQL + TimescaleDB 확장.
- **배치**: Airflow 또는 Prefect, 경량으로는 Celery Beat.
- **배포**: Docker + Kubernetes 또는 관리형(GCP Cloud Run/AWS ECS).
- **관측**: OpenTelemetry + Grafana/Prometheus + Sentry.

## 4. 도메인 모델 (핵심 엔티티 스케치)

```
Household (가구)
 └─ Member (구성원) ── Role(Owner/CoAdmin/Viewer)
        └─ Consent (개인정보·마이데이터 동의 이력)

Institution (금융기관/거래소/부동산 등)
Account (기관 내 계좌·지갑)
 ├─ owner: Member
 ├─ ownership_shares: [{member_id, ratio}]  # 공동 소유 지원
 └─ credentials: ConnectionToken (암호화)

Asset (자산 인스턴스)
 ├─ type: REAL_ESTATE | STOCK | FUND | ETF | PENSION | CASH |
 │        CRYPTO | GOLD_PHYSICAL | GOLD_FINANCIAL | VEHICLE | OTHER
 ├─ account_id (nullable: 실물은 계좌 없이 존재 가능)
 ├─ quantity, cost_basis_avg, cost_basis_total
 ├─ valuation_source: REALTIME | DAILY | MANUAL
 └─ metadata: JSON (종목코드, 주소/전용면적, 차량 VIN, 순도 등)

PriceQuote (일별 시세 스냅샷, Time-series)
 (asset_key, date, price, currency, source)

Liability (부채)
 ├─ type: MORTGAGE | CREDIT_LOAN | CARD_INSTALLMENT | PRIVATE_LOAN
 ├─ principal, balance, interest_rate, rate_type(FIXED/FLOAT)
 └─ schedule: [Payment]

CardTransaction / CashFlowEvent
 (date, amount, category, counterparty, member_id, account_id)

TaxProfile
 ├─ member별 과세 정보(보유주택수, 1세대1주택 여부, 장기보유공제 등)
 └─ HouseholdTaxSimulation (저장된 시뮬레이션 결과)

PortfolioTarget
 (household_id, target_allocation: {asset_class: ratio})
```

### 4.1 가족 단위 집계 규칙
- 모든 집계는 `ownership_shares` 기준으로 **지분 가중**으로 합산.
- 가구(Household) 기본 통화는 KRW. 해외 자산은 일별 환율로 평가.
- "실현 손익"은 `매도거래`, "미실현 손익"은 `현재가 - 평균매수가`로 분리 표기.

## 5. 외부 연동 — 소스별 전략

### 5.1 부동산
- **1차(공개)**: 국토교통부 실거래가 공공데이터포털 API → 주소/단지 기반 **최근 실거래가** 제공.
- **시세(호가/KB)**: KB부동산 공식 OpenAPI는 부재. 대안:
  - 한국부동산원 R-ONE (주택가격동향조사)로 단지 평균 추세 확보.
  - KB시세는 이용약관·법적 리스크 검토 후 스크래핑 여부 판단. **권장: 1차는 실거래가 + 부동산원 지수 기반 평가**로 시작.
- **보유세**: 공시가격(국토부 "부동산 공시가격 알리미") 조회 → 재산세 + 종합부동산세 계산.
- **양도세**: 취득가·보유기간·1세대1주택·조정대상지역 여부 등 입력 받아 장기보유공제·세율 적용.

### 5.2 금융자산 (은행/증권/카드/대출)
- **원칙**: 개인이 각 금융기관 API를 직접 호출하는 것은 일반적으로 불가능. **마이데이터**가 유일한 통합 경로.
- **구현 옵션**:
  - (A) **마이데이터 중계 서비스**(뱅크샐러드/토스 등) 파트너 연동 — 제휴 계약 필요.
  - (B) **오픈뱅킹(금융결제원)** — 은행 잔액·거래 조회 위주. 개인 개발자 등록 가능.
  - (C) **증권사 OpenAPI** (키움 OpenAPI+, 한투 KIS, 이베스트) — 본인 계좌 한정 조회 가능, 시세 스트리밍 포함.
  - (D) **CSV 수동 업로드** — 초기 MVP에서 반드시 제공.
- MVP 권장 순서: (D) → (C 일부) → (B) → (A).

### 5.3 암호화폐
- **업비트 Open API**: Access Key/Secret Key 발급 → `/v1/accounts`, `/v1/ticker`로 잔고·시세 취득.
- 빗썸/코인원도 동일 패턴으로 확장.

### 5.4 금
- 현물: **한국금거래소 공시가** / **KRX 금시장** 가격. 해외 참고: **LBMA** 일일 가격.
- 금융상품: 금 ETF(예: KRX에 상장된 금 현물 ETF 종목코드)는 주식과 동일 경로.
- **합산 로직**: `금 보유량(g) × 단위가격 + 금ETF 수량 × ETF가격` → 하나의 "금" 자산군으로 집계.

### 5.5 자동차
- 공식 공개 API는 제한적. KB차차차/엔카는 공식 OpenAPI가 없어 **(i) 수동 입력 + 감가상각 모델**, **(ii) 보험개발원 차량가액 조회(업무제휴)**를 조합.
- MVP: 제조사·모델·연식·주행거리 입력 → 중고차 시세 참고표(수동 유지) 기반 평가.

### 5.6 환율
- **한국은행 ECOS API** 또는 외환은행 고시환율. 일 1회 배치로 원화 환산.

### 5.7 시장 정보/종목 추천(정보 제공)
- KRX 공시(DART OpenAPI), 네이버 금융 스크래핑 대체로 FinanceDataReader/pykrx 등 오픈소스 활용.
- **주의**: "추천" 문구는 자문업 이슈 → **"관심종목 트렌드/거래대금 상위/공시 이슈"** 같은 **정보 제공** 형태로 UX 설계 + 면책 고지.

## 6. 세무 엔진 (설계 요점)

### 6.1 보유세 (매년 6/1 기준)
- 입력: 주택별 공시가격, 가구 보유 주택수, 공동명의 지분율, 고령자·장기보유 공제 여부.
- 출력: 재산세(주택분) + 도시지역분 + 지방교육세 + 종부세(합산 과세표준 기반).

### 6.2 양도세
- 입력: 취득일·취득가·필요경비·양도예정가·보유기간·거주기간·조정대상지역·1세대1주택 여부.
- 출력: 장기보유특별공제 → 과세표준 → 세율 → 지방소득세 포함 총세액. 시나리오 비교(지금 vs 1년 후).

### 6.3 금융소득종합과세 시뮬
- 이자·배당 연 2,000만원 초과 시 종합과세 → 근로·사업소득과 합산 시뮬.

### 6.4 절세 트래킹
- ISA / 연금저축 / IRP 연간 한도 잔여액 표시, 세액공제 효과.

## 8. UI/UX 구성(대시보드 초안)

1. **홈(Household Dashboard)**
   - KPI: 총자산, 총부채, 순자산, 당월 손익, 당월 현금흐름
   - 자산군별 도넛 + 구성원별 스택
   - 순자산 시계열(1M/3M/1Y/All)
2. **포트폴리오**
   - 주식 통합 홀딩(여러 계좌 합산), 섹터·지역·통화별 비중
   - 타깃 대비 편차 및 리밸런싱 제안
3. **부동산**
   - 단지/주소별 실거래가 추이, 보유세·양도세 시뮬
4. **현금흐름**
   - 월별 수입·지출, 카드사별·카테고리별 분해
5. **대출**
   - 잔액·금리·상환 스케줄·총이자비용 추이
6. **세무**
   - 연간 세금 달력(납부 예정일), 시뮬레이션 워크시트
7. **구성원/설정**
   - 초대·권한, 연동 상태, 동의 이력, 데이터 내보내기·삭제

## 9. 보안·컴플라이언스

- 전 구간 TLS, 토큰은 **Envelope Encryption**(KMS).
- 로그인: 이메일+비밀번호 + **2FA(TOTP/WebAuthn)**.
- 구성원 초대는 **가구 Owner 승인** + 이메일 링크 유효기간 10분.
- 개인정보 처리방침·이용약관·마이데이터 전송요구 동의 UX.
- 데이터 파기: 탈퇴 시 30일 내 파기(법정 보관 의무 예외 명시).
- 감사로그: 민감데이터 조회·시세 수집 실패 등 기록.
- **면책**: "본 서비스가 제공하는 정보는 투자 권유가 아니며 참고용" 고지 상시 노출.

|---|---|---|

| 클라우드 호스팅 | 금융 데이터 해외 이전 이슈 | 리전은 국내(서울) 고정 |

## 11. 개발 로드맵 (제안)
